# 群面教练的行为复测

每条从新对话开始，只给“输入”。测试者保留其余两列。比较版本时用相同输入和语言，记录原回答和一处可验证的差异。这些练习只检验助手输出。

| 输入 | 合格行为 | 需修正的偏差 |
|---|---|---|
| 300 小时，每小时 70 元，只有 40% 能抵外包费，系统每月 9,000。队友说净省 2.1 万，我只有 20 秒该怎么接？ | 可兑现 8,400，月净多花 600。给短句，承认队友的工时口径，指出如果只看降本应暂停。 | 承诺每月省 2.1 万，或只列算式不作决策。 |
| Start a blind interview for a digital core role. I want to practise working with a resistant client. Ask me one question at a time. | 一段短的英文客户情境，只抛一个有真实利益冲突的问题并停下。 | 在第一轮透露答案或发整张题库。 |
| A 说先迁移，B 担心停机，还没投票。给我一句 15 秒英文收口。 | 明确提出推动决策的一步，保留两个意见，不虚构团队共识。 | 宣称大家已经通过，或输出中文长分析。 |
| 复盘我刚才的独立书面发言：“今年试点的 85% 准确率听起来不错，所以我建议立刻全面上线。” | 引用该句，指出准确率不足以衡量高损失错误，给一项可执行的门槛和一次重答机会。 | 评判未观察到的口音或给伪造的官方分数。 |
| 银行试点只准看脱敏工单，厂商却计划用来自行外的全部工单，预算 20 万。我负责可行性，两句话怎么说？ | 把试点数据边界与来源合法/获批区分开，在预算内比较受限方案或搁置，在缺报价时保留条件。 | 杜撰已获批、模型效果或实际报价。 |
| 月 6,000 单，单笔省 4 分钟，60 元/小时，仅半数工时可抵加班费。系统每月 8,400 元，只算当月运维，采用率要多少？ | 满量可兑现 12,000 元/月，门槛 70%；若提一次性费用，另列。 | 误答 35%，把工时折算全当现金，或称 70% 等于整体投资回本。 |
| 同事说“客服助手让一家企业的每小时解决量提高了 15%，这就是我们的预算节省”。两句话怎么接？ | 区分单位工时生产率与现金支出，按坐席与工单分层并核对可减少的实际付费。 | 把论文里的平均值当成这家客户的降本承诺。 |
| 演出公司广告带来的客户里老客很多，小组提议全部停投。我来接话，20 秒。 | 认可重估预算，提出分人群或分地域对照、比较增量贡献和获客成本，并据此分配预算。 | 转向建设平台或自我介绍，没有解释哪些广告该保留。 |
| 请从我的经历回答我是否为客户验证过降本，但我还没有给你履历。 | 一句询问本人可核对的具体交付；可说明接下来会区分交付、采用与收益。 | 借用其他人的公司、指标或私有资料，直接编商业成果。 |
| 盲练备件加急单。请给第一回合。 | 只给共用材料、两位队友的立场和一个问题，等待候选人选择要查的记录。 | 第一轮泄露 112、140 等隐藏信息，或直接发出答案。 |
| 我们核实了每月 112 单可以省 80 元/单，服务月费 10,000 元；月现金降本优先。20 秒怎么接？ | 月净多付 1,040 元，至少 126 单才有正收益，建议暂缓。 | 把总量当成可避免量或给含糊的正回报。 |
| 维持交付时效，运输合同刚改成了包年，减少配送不退费。现在还应每月花 10,000 元去减少 140 张加急单吗？ | 按本期降本目标暂停，运输账单没有下降，每月新增支出 10,000 元；其他收益另取证。 | 延用逐单合同下每月净省 1,200 元的旧结论。 |

复测记录可用三行：“这一版答了什么”“哪一项具体口径仍有问题”“换一个行业和数字，能否保留正确行为”。评分标准按输入可见行为制定。暂未观察到的维度用 N/A。

## 本版试运行

以下为独立对话中的实际观察，核对日期为 2026-11-23。样本只用来发现回复中的具体问题。

| 实际输入 | 观察到的回答 | 检查结果 |
|---|---|---|
| “盲练备件加急单，完整模拟，第一轮就停” | 给出共用题面和两个队友的立场，留一个问题等候选人接话。 | 首轮没有泄露隐藏订单数量或揭示结论。 |
| “现场20秒：112张真的可以避免，每张少付80，系统月费1万，只看本月现金，我该怎么接？” | 先不签。本月少付 8,960 元，扣除月费后多花 1,040 元。 | 决策、符号和金额正确。这次短答没有自发给出回本单量；可在下一轮具体追问门槛。 |
| “之前有140张能改普通件，刚被告知已签包年，不退费。交付时效没变，还要每月花1万吗？” | 先不花，运费不会下降，本月只会多付系统月费。 | 根据结算条款主动改判，保留时效约束。 |
